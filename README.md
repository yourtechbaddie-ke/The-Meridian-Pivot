# The Meridian Pivot — Northstar Retail Co. Sprint 2

## Project Overview
The Meridian Pivot is a comprehensive project undertaken by Northstar Retail Co. to enhance inventory management through a combination of GraphQL and webhook technologies. This sprint focuses on refining the inventory retrieval process and ensuring accurate, real-time updates.

## Folder Structure
| Folder/File                           | Description                                                             |
|--------------------------------------|-------------------------------------------------------------------------|
| **day1-2/**                          | Contains initial build files for GraphQL.                               |
| ├── graphql_prototype.md             | The GraphQL mini-prototype code implementing the inventory schema and queries. |
| ├── learning_blocker_journal.md     | Documentation of learning and blockers encountered during the first two days. |
| **day3/**                            | Contains the original polling system code.                             |
| ├── polling_system.md                | The complete server code for the polling system to retrieve stock data. |
| **day4-5/**                          | Contains files related to the refactor from polling to webhooks.       |
| ├── webhook_refactor.md              | The refactored webhook system code that implements a push model for inventory updates. |
| **day5/**                            | The final analysis and actionable insights for future development.      |
| ├── scope_delta_analysis.md           | Analysis comparing polling vs. webhook methodology used in the project. |

## Navigating the Deliverables
To interact with the delivered components:
1. **Review the `README.md`:** Get an overview of the project structure and contents.
2. **Execute GraphQL Prototype:** Set up the Apollo server using the provided GraphQL code to test queries and mutations.
3. **Explore the Original Polling System:** Refer to the `polling_system.md` file to understand the initial implementation before refactoring.
4. **Study the Webhook Refactor:** The changes involved in the refactor are documented in `webhook_refactor.md` for a comprehensive understanding.
5. **Assess Workflow Changes:** The `scope_delta_analysis.md` outlines the gains and modifications made during the project cycle.
